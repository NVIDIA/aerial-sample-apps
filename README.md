# NVIDIA AI Aerial Sample Applications

A collection of example applications and reference implementations for the [NVIDIA AI Aerial](https://developer.nvidia.com/industries/telecommunications/ai-aerial) platform.

## Contents

- **[dapps/](dapps/)**: Distributed applications using the E3 interface
  for real-time RAN data processing and control, validated on
  [NVIDIA Aerial Testbed](https://docs.nvidia.com/aerial/testbed/latest/index.html).

Additional sample applications targeting other parts of the AI Aerial platform will be added in future releases.

Each component versions independently; per-release changes are listed in its own `CHANGELOG.md`.

## NVIDIA AI Aerial™

NVIDIA AI Aerial™ Sample Applications are part of [NVIDIA AI Aerial™](https://developer.nvidia.com/industries/telecommunications/ai-aerial), a portfolio of accelerated computing platforms, software and tools to build, train, simulate, and deploy AI-native wireless networks. Learn more in [AI Aerial™ Documentation](https://docs.nvidia.com/aerial/index.html).

The following AI Aerial™ software is available as open source:

- NVIDIA AI Aerial™ Sample Applications (this repository)
- [NVIDIA Aerial™ CUDA-Accelerated RAN](https://github.com/NVIDIA/aerial-cuda-accelerated-ran)
- [NVIDIA Aerial™ Omniverse Digital Twin (client)](https://github.com/NVIDIA/aerial-omniverse-digital-twin)
- [NVIDIA Aerial™ Framework](https://github.com/NVIDIA/aerial-framework)

Visit the [NVIDIA 6G Developer Program](https://developer.nvidia.com/6g-program) for software releases, 6G events and technical training for AI Aerial™.
