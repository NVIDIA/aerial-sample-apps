# NVIDIA AI Aerial Sample Applications

A collection of example applications and reference implementations for the [NVIDIA AI Aerial](https://developer.nvidia.com/industries/telecommunications/ai-aerial) platform.

## Contents

- **[dapps/](dapps/)** — Distributed applications using the E3 interface
  for real-time RAN data processing and control, validated on
  [NVIDIA Aerial Testbed](https://docs.nvidia.com/aerial/aerial-ran-colab-ota/current/index.html).

Additional sample applications targeting other parts of the AI Aerial platform will be added in future releases.
